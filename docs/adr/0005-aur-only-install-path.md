# AUR `tagwerk-git` is the only install path

The candidates were a symlink from a checkout into `~/.local/bin`, a PyPI package, a curl'd raw file and an AUR package. The symlink cost 14 README lines and made the unit, the pi extension and hypridle depend on `~/.local/bin` being on every PATH. pip and uv install a console script under whatever interpreter installed it, which reopens the hijack ADR-0004 closed. The AUR is Arch-native: one `paru -S`, `hypridle` as a hard dependency because without idle marks every polled minute is present and the ledger is silently wrong, the unit in `/usr/lib/systemd/user`, and `/usr/bin/tagwerk` on every PATH including Bun's.

Consequences: no clone in the install, `-git` tracks master with no release process, and CI publishes `contrib/aur` on merge. The user-home files (config, `hypridle.conf`, agent hooks) stay README lines; a `tagwerk setup` command would be a tenth of the codebase to save three of them. The PKGBUILD builds master, so a renamed `contrib` file and its PKGBUILD line ship in one PR.
